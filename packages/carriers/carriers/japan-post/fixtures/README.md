# Fixtures

These are synthetic reconstructions of Japan Post's English HTML table shape,
observed on 2026-09-26. Tracking numbers, dates, office names and postal codes
are invented. Alternating history rows, rowspan attributes, table summaries,
headers and the not-found sentence preserve the response contract.

`PRIVATE_` markers test that unrelated contact and free-form fields are not
projected into tracking results. No raw live response is committed.
