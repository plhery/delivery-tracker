# Colisweb fixtures

- `delivered.json` — a completed appointed delivery: the three milestone
  timestamps, the booked slot (`startsAt`/`endsAt`) and the retailer and
  recipient blocks the endpoint returns beside them. Constructed to the
  endpoint's shape around `10000000`, the number Colisweb prints in its own
  tracking form; the retailer and recipient values are placeholders the privacy
  assertion looks for.
