# C Chez Vous fixtures

- `out-for-delivery.json` — the record the tracking page embeds in its
  `<tracking :tracking-results="…">` attribute for a single-parcel order on step
  4: the parcel step and appointment date, plus the shop, recipient, contact,
  address, article and dealer fields that arrive with them. Constructed to the
  page's shape around `FGRC45BKLM`, the reference C Chez Vous prints as its own
  example; every personal value is a placeholder the privacy assertion looks for.
